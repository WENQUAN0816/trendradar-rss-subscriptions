# TrendRadar RSS Subscriptions

当前 TrendRadar 新闻配置包含 **46 个已启用 RSS 源**。本项目提供订阅清单和 `trendradar-news` skill。

## 文件

- `rss-feeds.opml`：可导入 Feedly、Inoreader 等阅读器。
- `rss-feeds.yaml`：TrendRadar 风格配置。
- `rss-feeds.json`：结构化订阅数据。
- `rss-feeds.csv`：表格格式。
- `skills/trendradar-news/SKILL.md`：新闻 skill 说明。
